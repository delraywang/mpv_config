# mpv-lazy 便携配置

这是 `mpv-lazy` 的 `portable_config` 配置目录，用于为 Windows 便携版 [mpv](https://mpv.io/) 提供开箱即用的播放体验。它在 mpv 核心配置的基础上集成了 uosc 图形界面、弹幕、时间轴缩略图、播放历史、自定义按键，以及着色器和 VapourSynth 预设。

将本目录放在 `mpv.exe` 同级目录，并保持目录名为 `portable_config`，启动 mpv 后便会自动加载其中的配置。

## 主要特性

- 使用 `gpu-next` 视频输出、自动硬件解码和显示器重采样同步。
- 采用 uosc 作为播放界面，提供播放列表、轨道选择、速度、时间轴、统计信息等控件。
- 集成弹幕搜索与显示、时间轴缩略图预览及播放历史菜单。
- 提供多组图像着色器与 VapourSynth 脚本预设，方便按需调校画质、插帧、降噪或超分。
- 保存播放进度、常用全局属性，并支持按视频文件夹分别保存片头片尾和播放速度。

## 目录说明

| 路径 | 用途 |
| --- | --- |
| `mpv.conf` | mpv 核心播放、音视频、字幕、截图、缓存与默认着色器设置。 |
| `profiles.conf` | 条件化配置预设，例如速度限制、自动去色带、HDR 与视频同步策略。 |
| `input_uosc.conf` | 键盘和鼠标快捷键配置。 |
| `menu.conf` | mpv 菜单配置。 |
| `script-opts.conf` | 脚本通用选项入口。 |
| `script-opts/` | uosc、弹幕、缩略图和播放历史等脚本的独立配置。 |
| `scripts/` | mpv Lua 脚本；其中包含 uosc、弹幕和本项目的自定义功能。 |
| `shaders/` | GLSL 着色器合集；当前默认启用 `QCOM/QCOM_SGEDS_ms_RT.glsl`。 |
| `vs/` | VapourSynth 处理预设，包括插帧、降噪与超分相关脚本。 |
| `fonts/` | 界面与字幕使用的本地字体。 |
| `_cache/` | mpv 运行时缓存，如着色器缓存、缩略图缓存、断点续播和历史记录；通常不需要手动编辑。 |

## 自定义脚本

以下脚本位于 `scripts/`，无需额外注册，mpv 会自动加载其中的 Lua 文件。

### `right_hold_speed.lua`：右方向键短按跳转、长按倍速

- 短按并松开右方向键：向前跳转 5 秒。
- 按住超过 0.4 秒：临时将速度切换为 2 倍；若原速度已达到 2 倍，则临时切换为 3 倍。
- 松开右方向键：恢复按下前的播放速度。

该脚本接管 `RIGHT` 按键，因此 `input_uosc.conf` 中没有再为右方向键设置单独绑定。

### `skip_intro_outro.lua`：按文件夹跳过片头和片尾

此脚本为本地视频所在的每个文件夹保存独立配置。在 uosc 控件栏中点击“片头片尾设置”按钮，可以开启或关闭自动跳过、直接输入片头/片尾时长，或将当前播放位置一键设为片头/片尾。

- 片头保存的是要跳转到的时间；开始播放时，如果不是从更靠后的位置续播，脚本会跳至此处。
- 片尾保存的是“距视频结尾的时长”；播放进入该范围后，脚本会通过 uosc 切换到下一个文件。
- 支持秒数、`MM:SS` 和 `HH:MM:SS` 格式。
- 设置保存在视频目录的 `.mpv/settings.conf` 中，仅对该目录的本地视频生效。

### `video_speed.lua`：按文件夹保存和恢复播放速度

此脚本会为本地视频所在的文件夹记住播放速度，并在之后加载该目录中的视频时自动恢复。速度变化后会延迟保存，也会在文件结束或关闭 mpv 时保存。

- 默认可保存和恢复 0.1–10 倍速，默认延迟 0.8 秒。
- 配置和速度值保存在视频目录的 `.mpv/settings.conf` 中；可通过 `video_speed_enabled`、`video_speed_save_delay`、`video_speed_min_speed` 和 `video_speed_max_speed` 调整行为。
- 脚本会与片头片尾脚本共用同一个配置文件，并保留其中不属于自身的字段和注释。
- 可用脚本消息 `video-speed-save` 立即保存，或用 `video-speed-clean` 清除当前目录已保存的速度值。

## 使用与维护

大多数选项都附带中文注释，建议优先在对应配置文件中修改。修改 `mpv.conf` 中已被全局属性保存功能追踪的项目（例如 `volume` 或 `glsl-shaders`）后，如发现旧值仍被恢复，可在确认不再需要原记录后删除 `_cache/saved-props.json`。

视频目录下自动生成的 `.mpv/settings.conf` 是媒体文件夹自己的设置，不属于本配置目录；如需重置某个文件夹的片头片尾或倍速，可编辑或删除该文件夹中的对应字段。
